📐 Estimation Methods Reference
COCOMO Basic
Effort = a × (KLOC)^b (person-months) Duration = c × (Effort)^d (months) Staff = Effort / Duration Organic: a=2.4, b=1.05, c=2.5, d=0.38 Semi: a=3.0, b=1.12, c=2.5, d=0.35 Embedded: a=3.6, b=1.20, c=2.5, d=0.32
Function Point Analysis
Count: External Inputs, Outputs, Inquiries, Internal Files, Interfaces Each weighted Low/Avg/High UFP → Apply Value Adjustment Factor 1 FP ≈ 53 LOC (Java/C#) FP / team productivity = duration
Planning Poker (Agile)
Fibonacci sequence: 1,2,3,5,8,13,21 Each team member estimates silently Reveal simultaneously → discuss gaps Re-estimate until consensus Story points ≠ hours (relative size) Base story = 1 point reference
