🔠 CAESAR CIPHER
ROT-N substitution cipher. Shift each letter by N positions.
Shift = 3
DWWDFN DW GDZQ
📊 SHIFT TABLE
Alphabet Mapping (Shift = 3)
ℹ️
History: Used by Julius Caesar (58 BC) for military communications. ROT-13 (shift=13) is the most common modern variant. Easily broken with frequency analysis.
🔍 FREQUENCY ANALYSIS (Attack on Caesar)
In English, 'E' is most frequent (~12.7%). By analyzing letter frequencies in ciphertext, the shift can be determined — making Caesar cipher cryptographically weak.
⚠️
Caesar cipher is NOT secure for real use. It provides only 25 possible keys — brute-forceable in seconds.
🔑 VIGENÈRE CIPHER
Polyalphabetic cipher — each letter uses a different Caesar shift based on the keyword.
📐 HOW IT WORKS
Encryption Formula
Cᵢ = (Pᵢ + Kᵢ) mod 26 Dᵢ = (Cᵢ - Kᵢ + 26) mod 26 Where: Pᵢ = Plaintext letter position (A=0) Kᵢ = Key letter (repeating) position Cᵢ = Ciphertext letter position
ℹ️
Vigenère resisted decryption for ~300 years until Kasiski (1863) found a way to break it by finding repeated patterns to determine key length.
⊕ XOR ENCRYPTION
Bitwise XOR — the foundation of stream ciphers and modern symmetric encryption (AES).
